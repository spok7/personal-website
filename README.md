# My Website!

Hello! This is my website made with Hugo using the Academia theme, with some custom JavaScript littered in.

You can run this locally with `hugo server` (or in debug mode with `hugo server -D`) and build the static site with just `hugo`.
Since this site is already outdated, docs to it can only be found [here](https://bootstrap.hugoblox.com/content/blog-posts/).

Follow [this guide](https://gideonwolfe.com/posts/sysadmin/hugonginx/) for more info on how to set up a hugo website.
